## 📖 Notes Approach

Whenever possible, concepts are documented with a focus on:

* **What** is the concept?
* **Why** does it matter?
* **How** does it work?
* **Where** is it used?
* **When** should it be used?
* **How** can it be implemented?

The goal is to focus not only on memorizing concepts but on developing a deeper understanding through **intuition, mathematics, implementation, and practical examples**.
